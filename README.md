# WWE Universe Tracker

Puerta de entrada (con ícono propio) a la web del tracker del modo Universo de WWE 2K26.
La web real vive en Google Apps Script; esta página solo la abre a pantalla completa.

Para instalarla en el iPhone: abre el link en Safari → Compartir → **Agregar a pantalla de inicio**.

Si cambia la dirección de la web de Apps Script, se actualiza en `index.html` (variable `WEB`).
